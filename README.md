# AGENTRIX26-TEAM21-QuadNova

Welcome to the AGENTRIX26-TEAM21-QuadNova project repository!

## Overview
This project contains a full-stack application consisting of:
- **Backend**: API and server logic (`/backend`)
- **Frontend**: User-facing web application (`/frontend`)
- **Admin Frontend**: Administrative dashboard (`/admin-frontend`)

## Getting Started

### Prerequisites
- Docker and Docker Compose (recommended for running the full stack)
- Node.js and npm (for local development on frontends)
- Python (for local development on backend)

### Running with Docker
You can start the entire stack using Docker Compose:
```bash
docker-compose up --build
```

## Structure
- `/admin-frontend`: Admin dashboard frontend application.
- `/backend`: The backend service.
- `/dataset`: Datasets used for the application.
- `/docs`: Documentation.
- `/frontend`: Main frontend application.
- `/scripts`: Utility scripts.
