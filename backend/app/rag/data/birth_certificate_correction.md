# Official Service Rules: Birth Certificate Name Correction (Civil Registry)

**Service Name**: Birth Certificate Name Correction
**Service ID**: birth_certificate_correction
**Category**: Civil Registry & Vital Records
**Office Type**: Divisional Secretariat (Registrar of Births/Deaths/Marriages branch)
**Official Fee**: 150 LKR (stamp duty)

## Description
Correction of spelling mistakes or omissions in father's/mother's names or child's name on a birth certificate.

## Sequential Dependency: Correction before Passport Application
A passport application requires an accurate birth certificate matching the National Identity Card. Thus, the birth certificate must be corrected **first** before submitting the passport application.

## Required Documents
1. **Application Form (Section 27)**: Duly completed application form.
2. **Original Birth Certificate**: The erroneous copy to be corrected.
3. **Certified Affidavit**: Declaring the spelling mistake and confirming the correct spelling.
4. **Supporting Documents**: Parents' marriage certificate, parents' birth certificates, or NIC showing correct spelling.
